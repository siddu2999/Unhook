Unhook
A simple Chrome extension to reduce distractions on YouTube.**

Unhook helps you customize your YouTube experience by hiding distracting elements so you can focus on the videos you actually want to watch.

## Features

- **Hide YouTube Shorts** — Remove Shorts shelves from YouTube.
- **Hide Recommendations** — Hide recommended videos on the watch page.
- **Hide Comments** — Hide the comments section.
- **Simple Controls** — Enable or disable each feature using the extension popup.
- **Persistent Settings** — Your preferences are saved using Chrome Storage.

## Installation

### Step 1: Download the Source Code

1. Click the green **Code** button.
2. Select **Download ZIP**.
3. Extract the downloaded ZIP file to a folder on your computer.

### Step 2: Add Unhook to Chrome

1. Open Google Chrome.
2. Enter `chrome://extensions` in the address bar and press Enter.
3. Turn on **Developer mode** using the toggle in the top-right corner.
4. Click **Load unpacked**.
5. Select the extracted **Unhook project folder** containing `manifest.json`.
6. Unhook should now appear in your Chrome extensions list.

### Step 3: Use Unhook

1. Open YouTube.
2. Click the Extensions icon (puzzle piece) in Chrome's toolbar.
3. Select **Unhook**. You can pin it to the toolbar for easier access.
4. Use the available switches to hide or show Shorts, recommendations, and comments.
5. Refresh YouTube if a change does not appear immediately.

**Note:** This installation method requires Developer mode and is intended for personal use and testing. Unhook is not currently installed through the Chrome Web Store.

## Updating Unhook

1. Download the latest source code from GitHub.
2. Extract the updated files into a folder.
3. Open `chrome://extensions`.
4. Click **Reload** on Unhook if you updated the existing extension folder. If you use a new folder, click **Load unpacked** and select it.
